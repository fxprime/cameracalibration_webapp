# Development guide

Use CodeGraph for structural source exploration and native text tools for literal strings or already identified files. Run `codegraph sync .` after edits. Keep Rust transport, OpenCV numerical code, target geometry and UI independent. Preserve explicit units and coefficient order. Never export fictitious IMU/stereo transforms or label browser PNGs as sensor RAW. Numerical changes need synthetic ground-truth tests; UI changes need browser workflow verification. Captured images, sessions, builds and index are ignored by Git.
